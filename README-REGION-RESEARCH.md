# Regional SAT Lead Research

Web-приложение для последовательного выполнения 10 исследовательских инструкций по выбранному региону с OpenAI Responses API и встроенным `web_search`.

## Сценарий
1. Пользователь выбирает/вводит регион и вводит OpenAI API key.
2. Шаги 1–9 выполняются строго последовательно.
3. Их промежуточные результаты остаются только в памяти браузера и пользователю не показываются.
4. Шаг 10 получает общий пул, выполняет глобальную дедупликацию, перепроверку и финальную классификацию.
5. Браузер формирует один XLSX с листами `Прямые покупатели`, `Посредники`, `Лизинг`, `Статистика`.
6. Столбца `Источник` в итоговом файле нет.

## OpenAI
Приложение вызывает `POST https://api.openai.com/v1/responses`, передаёт `tools: [{ "type": "web_search" }]` и `tool_choice: "required"`.

GitHub Pages является статическим хостингом и не хранит серверные секреты. Поэтому API key вводится в интерфейсе, используется только в текущей вкладке и не сохраняется в localStorage/cookies/репозитории.

## Ветка
Приложение находится в ветке `region-research-app`, чтобы не изменять существующий код `main`.

## Публикация
Workflow `.github/workflows/pages.yml` публикует эту ветку через GitHub Pages.
