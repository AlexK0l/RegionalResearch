# SAT Region Research — Render edition

Ветка `render-app` содержит серверную версию приложения для Render.

## Архитектура

- **Web Service** — интерфейс, API создания заданий, отображение прогресса и скачивание XLSX.
- **Background Worker** — последовательно выполняет инструкции 1–10 через OpenAI Responses API + `web_search`, затем шаг 11.
- **Render Key Value** — очередь BullMQ, прогресс и временное хранение итогового JSON.
- **Chromium + Playwright** — виртуальный браузер для шага 11.
- **OpenAI Computer Use** — GPT управляет браузером через действия мыши/клавиатуры и скриншоты.
- **Google API не используется.**

## Шаг 11: Google AI Mode

После глобальной дедупликации все компании с листов:
- Прямые покупатели
- Посредники
- Лизинг

последовательно прогоняются через браузер.

Для каждой компании:
1. Chromium открывает Google Search по названию + ИНН.
2. GPT через Computer Use пытается переключиться в **Google AI Mode** через интерфейс Google.
3. Ищет публичный телефон и руководителя/ЛПР.
4. Проверяет, что найденный контакт относится к точному юридическому лицу.
5. Подтверждённый телефон дополняет поле `Телефон`.
6. Подтверждённый ЛПР обновляет `Руководитель / ЛПР`.

Если Google AI Mode недоступен, требует входа или появляется CAPTCHA/bot challenge, приложение **не пытается обходить защиту**. Компания получает статус unavailable для этапа контактов, и worker переходит к следующей.

Пользователь видит прогресс вида:

`Google AI Mode: 43 / 127 · ООО ...`

Итоговый XLSX доступен только после завершения шага 11.

## Render Blueprint

В корне есть `render.yaml`, который создаёт:
- `sat-research-queue` — Render Key Value
- `sat-region-research` — Web Service
- `sat-region-research-worker` — Background Worker

Все ресурсы размещаются в регионе Frankfurt.

## Обязательные переменные

При создании Blueprint Render попросит:
- `OPENAI_API_KEY` — OpenAI API key
- `APP_PASSWORD` — необязательный пароль для входа в приложение

Ключ OpenAI не попадает в браузер и не хранится в GitHub.

## Запуск

Render должен быть подключён к GitHub и к ветке `render-app`.
Создайте Blueprint из этого репозитория и ветки. После первого успешного deploy откройте URL Web Service.

## Ограничения

Google может не показывать AI Mode конкретной датацентровой браузерной сессии, может потребовать вход либо показать anti-bot challenge. Приложение не обходит эти ограничения. Для стабильности browser worker обрабатывает компании последовательно (concurrency = 1).
