ОБЪЕДИНЕНИЕ, ГЛОБАЛЬНАЯ ДЕДУПЛИКАЦИЯ И ФИНАЛЬНЫЙ XLSX
Пользовательский пул результатов шагов 1–9 по одному региону нужно объединить в один итоговый результат, глобально удалить дубли, сохранить всю полезную информацию, перепроверить доказательность, заново классифицировать организации, проверить управляющие компании, контакты и ЛПР и сформировать лист «Статистика».
Не запускай новый массовый поиск лидов. Web search используй точечно для уже найденных организаций, разрешения дублей, проверки доказательств, телефонов, ЛПР, управляющей компании, выручки, численности и региональной статистики.

1. Собери все строки коммерческих групп в один временный пул и дедуплицируй глобально.
2. Нормализуй ИНН (только 10/12 цифр), название, телефон, сайт/домен, e-mail, город/район/адрес, при наличии ОГРН/ОГРНИП. Не заменяй юридическое название сравнительным ключом.
3. Валидируй структурированные поля: ИНН только корректный или пусто; телефон только подтверждённый; выручка/численность только подтверждённые значения с годом. Столбца «Источник» в итоговом XLSX нет.
4. Общий номер группы, колл-центр, общий домен холдинга, сайт каталога, общий e-mail группы не являются самостоятельным доказательством дубля.
5. Дедупликация: одинаковый подтверждённый ИНН = одна организация. Разные подтверждённые ИНН никогда не объединять. Без ИНН объединяй по индивидуальному телефону/домену/e-mail + дополнительному признаку либо по сильному совпадению нескольких признаков без противоречий. Не объединяй автоматически по похожему названию, общей управляющей компании, холдингу, бренду, директору, групповому сайту или общему адресу. При сомнении — точечная проверка.
6. При объединении дублей не теряй сведения: корректное наименование, подтверждённую управляющую компанию, ИНН, точный город/район; объедини уникальные сведения о технике/сегменте; сформируй новое краткое «Основание»; объедини подтверждённые телефоны через «;»; выбери самое конкретное следующее действие, сильнейшие причины звонка, наиболее профильного подтверждённого ЛПР, свежую выручку/численность. При конфликте юридических данных приоритет: официальный реестр/документ → официальный сайт → закупочные/судебные документы → проверенная бизнес-база → агрегатор.
7. Пересчитай A/B/C по итоговой совокупности фактов, не переноси механически.
8. Переклассифицируй по листам: «Лизинг» — только коммерческие лизинговые/финансовые организации; «Прямые покупатели» — потенциальные конечные пользователи/эксплуатанты; «Посредники» — сервисы/дилеры/экспедиторы без подтверждённой собственной эксплуатации и другие каналы. Одна организация — один коммерческий лист.
9. Оставляй только релевантные организации: должен быть целевой груз или реалистичный сценарий регулярной тяжёлой перевозки целевого сыпучего/объёмного груза.
10. Перепроверь управляющую компанию; если подтверждён холдинг/головная структура, но отдельная УК не установлена, укажи подтверждённую головную организацию/холдинг и кратко поясни связь в «Основание»; иначе «не подтверждена».
11. ЛПР: для перевозчиков — собственник, транспортный директор, руководитель автопарка, начальник АТП, главный механик, руководитель логистики; для грузовладельцев — директор по логистике, транспортному отделу, главный механик, снабжение, АТП; для посредников — собственник, коммерческий директор, руководитель сервиса/продаж; для лизинга — руководитель корпоративного лизинга/грузового транспорта. Если человек не подтверждён — пусто.
12. Выручка и численность — самые свежие подтверждённые значения с годом; не подставляй показатели холдинга отдельному юрлицу без прямого подтверждения.
13. Лист «Статистика» по всему региону должен содержать 8 показателей: население региона; количество лесных хозяйств; перевозчиков промышленных и бытовых отходов; дорожных ремонтно-строительных компаний; агро-хозяйств; деревообрабатывающих компаний; производителей ДСП; компаний по вывозу металлического лома/вторчермета. Для населения — самый свежий официальный показатель; для компаний — официальные реестры/статистика или воспроизводимый расчёт с описанной методикой; если точное число нельзя воспроизводимо получить — «н/д» и причина/методика. Не смешивай разные сущности. Компании, найденные только ради статистики, автоматически не добавляй в коммерческие листы.
14. Итоговая структура XLSX: 4 листа — «Прямые покупатели», «Посредники», «Лизинг», «Статистика». Первые три — ровно 12 колонок без «Источник»: Организация; Управляющая компания; ИНН; Город/район; Техника/сегмент; Основание; Телефон; Следующее действие; Почему им нужно звонить / потенциальный интерес к САТ; Руководитель / ЛПР; Выручка последнего подтвержденного года; Численность. «Статистика»: Показатель; Значение; Единица измерения; Период / дата актуальности; Методика / примечание.
15. Финальный QA: один подтверждённый ИНН не встречается более одного раза; одна организация не находится на двух коммерческих листах; очевидные дубли схлопнуты; разные юрлица одной группы не объединены; каждый A/B/C обоснован; управляющая компания перепроверена; прямые покупатели релевантны; ИНН и телефоны валидны; первые три листа имеют ровно 12 колонок; статистика содержит 8 обязательных показателей и 5 колонок; нет пустых технических строк, скрытых служебных полей, явных дублей и выдуманных данных.
